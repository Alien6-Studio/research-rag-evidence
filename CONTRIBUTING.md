# Contributing

Use English for code, documentation, issues and labels. Preserve original data
text, attribution, exact requests, responses, failures and actual collection dates.

Keep changes reproducible and follow the active repository protections.
New observations belong in a separate run directory.

Run all README controls, especially `python -m v2.verify`, before publication.
Calculations must work without Ollama. Keep human correctness, whole-context
support, citation-only support, citation IDs and justified abstention separate
from lexical scores. No assistant or automated judge supplies missing human labels.
Annotation keys and participant identities stay outside the public repository.

Code uses Apache-2.0; preserve third-party licenses and the HotpotQA CC BY-SA 4.0
attribution described in THIRD_PARTY_NOTICES.md. Sign the final contribution off
under the Developer Certificate of Origin with `git commit -s`.
